**Status convention:** `Complete` is reserved for a production path proven end to end. `Candidate verified` means a candidate feature has evidence in the isolated candidate database; it does not mean a canonical cutover or full route integration.

This matrix is the Phase 0 inventory for the explicit productionization objective. ## Interpretation

The matrix shows a useful amount of domain and UI scaffolding, plus a working legacy path for several local operations. It does not show a production-complete capability. The highest risk sequence is identity and persistence, pricing isolation, checkout/payment/inventory, and then customer/reseller/admin parity. A row may move to `Complete` only when its route, server use case, authorization, durable state, authoritative source, audit behavior, and tests all pass together.
